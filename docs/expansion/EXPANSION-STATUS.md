## 四、设计要点

1. **动画不决定业务**：先落状态，再排队播动作；没素材就静默跳过。
2. **缺动作不借衣服**：造型没有某动作时明确拒绝，绝不回退默认服装的帧。
3. **一次只做一件事**：同时只有一个活动任务、一张待处理健康卡、一个玩具会话。
4. **不补发**：休眠/锁屏醒来不弹一串提醒；旧候选过期。
5. **数据可恢复**：原子写 + 坏档备份 + 读失败禁止覆盖 + revision 冲突保留草稿。
6. **低打扰**：勿扰时不弹卡只记录；忽略卡片不扣好感。

### 服务中断期间的做法：派生动作

不能调用视频模型时，用 `scripts/pipeline/derive_actions.py` 从已有帧**重排**出
新动作。只做四种可信变换，绝不生成新画姿：

| 模式 | 做法 | 例子 |
|---|---|---|
| `reverse` | 反向播放 | 整理→摆好 |
| `slow` | 每帧重复一次 | 慢慢挥手 |
| `hold` | 首尾各停 4 帧 | 敬礼预备 |
| `pingpong` | 正放后倒放 | 来回倾听 |

产出 24 个变体，全部通过帧尺寸/脚底/帧数校验。**需要全新姿势的动作仍等
服务恢复。**
服务恢复后可直接重跑，脚本全部支持断点续跑：

```bash
cd scripts/pipeline
/tmp/mimienv/bin/python gen_action.py queue      # 默认外观剩余动作
/tmp/mimienv/bin/python build_assets.py          # 重建 manifest
```

## 八、抠图修复（2026-10-29）

**问题**：生成素材的绿幕抠图质量差，边缘有一圈白/绿边，轮廓上还有针孔（背景透出来）。

**根因**：早期用「颜色距离 + 硬阈值」抠图，只把明显接近绿背景的像素设为透明，
其余半透明像素保留了绿色；硬阈值又在轮廓上留下锯齿与小孔。

**修复**（`scripts/pipeline/fix_mattes.py`，不重生成素材）：
1. 以 alpha>100 为种子做形态学闭运算，补掉 ≤4px 的针孔；
2. 0.7px 羽化，得到抗锯齿边；
3. 对**所有可见像素**去绿（绿通道压到红/蓝较大值以下）；
4. 透明区 RGB 填成边缘中位色，缩放时不会混出黑边或绿边。

**结果**：

| 指标 | 修复前 | 修复后 |
|---|---|---|
| 平均绿边 | 20.1% | **0.0%** |
| 抽样 200 帧绿边 >2% | 116/120（抽样） | **0 / 200** |
| 素材体积 | 978 MB | **593 MB**（-39%） |
| 修改帧数 | — | 15,989 / 18,285 |

体积下降是附带效果：干净的 alpha 压缩率远高于带噪点的边缘。

**注意**：`green_ratio` 必须先把像素转 int16 再比较——uint8 相减在
g < r 时会下溢成很大的正数，曾把 0% 报成 11.6%，导致误判修复无效。

## 九、素材降采样（2026-10-29）
