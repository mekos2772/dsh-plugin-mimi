# Mimi 扩展实装进度

更新时间：2026-10-29。运行代码已改，素材由视频 / 生图模型产出。

**当前结果：10 套造型全部为「日常套装」，每套 6 个动作（深海女仆 5 个）；默认外观新增 20 个动作，动作总数 43。**

## 已完成

### 造型系统（预设套装）
- `outfits.py`：造型目录加载、严格白名单、持久化选择、冲突与缺件处理。
- 造型分 `display` / `daily`；`daily` 必须齐 `walk_right, head_pat, cheek_poke, celebrate` 才算完整。
- 每套造型带自己的 `action_map`（语义动作 → 该造型帧序列）。
- `engine.set_outfit()`、`_outfit_spec()`、`perform/force_perform` 造型优先。
- 缺某动作时不借用默认服装的帧，直接拒绝——不会出现“走路变回旧衣服”。
- 造型在待机与动作结束后立即接管画面，动作期间不闪默认外观。
- 右键菜单新增 **造型** 子菜单，可切换并显示“还缺几个动作”。

### 新动作（默认外观）
已生成并接入 20 个：伸懒腰、抱杯喝水、展开便签、铅笔思考、整理小桌面、整理装束、
转身展示、摸口袋、推小球、接星星、戴耳机、收灯、打招呼、点头、摇头、打哈欠、
开心跳、侧头听、害羞、鼓掌。动作总数 23 → 32+。

### 素材产线（scripts/pipeline/）
- `mimi_gen.py`：生图 / 视频提交轮询 / 绿幕抠像 / 统一缩放与脚底对齐 / webp 导出。
- `gen_outfit.py`：10 套预设造型。
- `gen_action.py`：默认外观的动作视频队列。
- `gen_preset_anim.py`：每套造型的待机循环。
- `gen_outfit_actions.py`：**每套造型 × 9 个动作**，分 A/B 级。
- `build_assets.py`：整理成 `expansion_v1/`，自动镜像左走、判定日常套装、写 manifest。

### 验证方式
- 离线渲染：`QT_QPA_PLATFORM=offscreen` + `QtRenderer`，逐帧真实合成。
- 已验证 `knit_home` 六个动作全部使用造型自己的帧。
- 脚底对齐：49 帧全程 bottom=744，高度波动 2–4%。
