# Mimi 角色参考图

用于给生图／生视频模型做角色一致性参考，也用于美术对比例。图片均从当前正式素材裁切生成，未改动原始资产。

| 文件 | 内容 | 用途 |
|---|---|---|
| `character-reference-sheet.png` | 母版设定 + 3 个表情 + 坐姿待机 + 3 个走路帧 + 摸头/击掌/开心/睡觉 + 3 档拖拽 | 一次给模型看全角色与常见姿态 |
| `character-proportions.png` | 角色本体加水平刻度线（呆毛顶、发顶、眉眼、下巴、领口、腰线、裙摆、脚踝、脚底） | 定位裁切、对齐锚点、检查新图比例 |

原始素材位置：`pet/assets/characters/mimi/library_v1/usable/`（母版在 `live_rig_v5/source/`，动作帧在 `actions/*/frames/`）。

## 关键比例（母版 1024×1536）

- 角色包围盒：x 201–824，y 621–1488，宽 624、高 867。
- 发顶 y≈660，眼睛中线 y≈940，下巴 y≈1100，脚底 y≈1488。
- 头高（发顶→下巴）约 440 px，头身比约 1 : 1.9，属于三头身左右的 Q 版比例。
- 正面站姿重心在中线 x≈512。

新画的动作帧必须落在同一画布与同一脚底基准上。**不要按每帧透明外框重新缩放**，那会让角色在动作里忽大忽小。

## 喂给生图模型的用法

1. 同时提供 `character-reference-sheet.png` 和 `character-proportions.png`，让模型同时看到"长什么样"和"多大、在哪"。
2. 明确要求**只换服装，不改脸、发型、瞳色、头身比、画风**。
3. 一次只改一个变量（先定衣服，再做表情，再做动作），不要一句话里同时换装又换姿势。
4. 生成后按比例图核对：发顶、下巴、脚底三条线必须落在同一高度，否则这一张不能用作动作帧。
5. 需要透明背景时先生成纯色背景再抠图，不要让模型直接生成透明通道。

提示词骨架：

```text
角色：蓝紫长发 Q 版少女，蓝色大眼睛，呆毛，白色蕾丝头饰，鲸鱼围裙，
     三头身比例，正面全身站姿，脚底对齐画布底部，2D 插画风格。
一致性：保持脸型、发型、瞳色、肤色、头身比、线条粗细和上色方式与参考图完全一致。
只修改：<这里写具体服装变化>。
输出：单角色、纯色背景、全身完整、不裁切、无文字、无水印。
比例：头部占身高约 1/2，脚底留少量空白，角色水平居中。
```

## 喂给生视频模型的用法

- **待机微动**：以单张定稿图作为首帧，要求极小幅度的呼吸与眨眼，不要位移、不要镜头运动。这类需求成功率最高。
- **走路**：以走路参考帧作为首帧或风格参考，明确要求侧身或四分之三视角、原地行走、循环、脚底不下沉。仍要预期脚底打滑与服装抖动，生成结果更适合当参考，不宜直接当正式资产。
- **换装展示**：用定稿图做首帧，要求轻微转身展示服装，时长 2–3 秒，避免大幅变形。

视频模型给的是运动参考。要落到项目里，仍需逐帧导出、对齐脚底基准、检查循环首尾衔接，再进 manifest。

## 已知限制

- 现有动作是整帧图片序列，衣服画在每一帧里，没有独立服装层。
- 因此"同一套动作穿不同衣服"无法自动得到；预设造型需要各自准备对应动作资产。
- 逐帧独立生成仍会出现脸部和服装细节跳变，参考图只能降低概率，不能消除。
