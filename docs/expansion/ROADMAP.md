# Mimi 开发清单：预设造型路线

状态：设计与计划，尚未实现。本文是当前产品范围与优先级的最新口径。
取代旧设计中自由配饰混搭、配饰轨道与衣帽架的首版计划；其他详细交互可参考 FEATURE-SPEC.md，但涉及穿搭的部分以本文为准。

## 一、已确定的方向

- 保留现有 PySide6、整帧动画、DSH 集成、领域状态机与既有23套正式动作。
- 不迁移 Spine/Live2D/Godot，不重做骨骼系统。
- F05 从“小衣帽架”改为“预设造型册”：完整造型配完整资产，不做任意单件混搭。
- 新造型先做一套样板；先证明待机稳定，再验证走路。逐帧独立生图仍有身份和画面跳变风险，预设不消除这个风险。
- 功能和美术分开验收：没有新素材时，工具功能仍可使用，不假装已有新动画。

## 三、F05 预设造型册的明确规格

### 3.1 两种产品等级
- 展示造型：只提供审核通过的待机表现；启用时明确进入展示模式，不走路、不播放不兼容动作；仍可关闭、打开菜单与退出展示。
- 日常套装：有一份明确的必要动作能力表，所有启用交互都有对应表现与退出路径。走路、拾取拖拽、释放落地和必要过渡未齐，不标日常。
- 默认套装仍为现有完整运行体验；新造型没做某个可选趣味动作就不触发，不偷偷借默认衣服的帧。
- 展示模式允许鼠标拖动窗口位置，但不使用旧服装拖拽/落地动画；采用静态移位，释放直接约束到可见区域。必须与正常物理拖拽逻辑显式分流。

### 3.2 造型卡片
名称、定稿预览、等级、可用动作、缺失能力、资源状态、应用按钮；不展示虚构的完整度百分比。
首版只有“默认造型+1套新主题”，新主题在样片未通过前不作为可用产品。
预览使用造型专属卡片或独立预览区，不先修改实际宠物；取消后当前造型不变。

### 3.3 安全切换流程
选择→检查资产与能力→预载首帧→等待安全待机点→切换资源映射→首帧成功绘制→保存当前造型。
拖拽/坠落/落地中显示“结束当前动作后切换”，只保留最后一次选择；5秒内没到安全点取消等待并提示重新操作，不强行打断。
资源失败恢复旧映射，旧映射释放前不销毁旧首帧；持久化失败显示本次已切换但尚未保存，不误报失败后重新切一遍。
重启找不到已选造型时回默认并提示一次，保留缺失造型偏好供用户查看，不反复尝试。

### 3.4 资源与代码
新增 proposed OutfitCatalog 和 OutfitService，而不是在既有ActionSpec里塞服装逻辑。
建议字段：Outfit{id,name,mode,asset_version,preview,rig_or_idle,action_map,capabilities,transition_policy}。
ID和路径只来自审核目录；首版无远程下载/任意文件夹导入。能力随资产版本绑定，缺必要映射不能标为ready。
引擎继续请求语义动作ID，由当前造型的 action_map 解析具体素材。旧manifest先通过适配器作为默认造型，不一次改坏现有资产。
关闭未适配的自主动作时同时关闭对应调度入口，不只在播放器报错；触摸等用户入口显示明确的静态回应或禁用理由。

## 四、实施顺序：不把所有功能一起开工

### 阶段A：造型技术验证 + 实用功能
- 工程：造型目录/能力描述/默认造型适配器/展示模式/安全切换。
- 美术：一套新主题定稿→稳定待机样片→走路样片。先不补完整23套。
- 功能：F01便签、F02三步任务，独立于美术开发。
- 通过条件：旧默认全功能回归；展示模式不漏播旧衣服；新待机与走路样片人工验收。没有通过不扩套装数量。

### 阶段B：完成第一套新造型 + 陪伴闭环
- 根据验证结果补齐新造型的必要动作后，才升级为日常套装。
- F03收尾卡、F08健康计划；F03首版不依赖尚未做的布景。
- 新动作优先A02喝水、A03展便签、A10接星星，逐套造型制作并标能力；没素材静态卡可用。

### 阶段C：小空间与轻娱乐
- F07一套小布景→F04静态跟听→F06一种玩具。
- 性能、鼠标穿透与生命周期清理通过后再加模板和动态效果。
- 根据第一套日常主题的实际制作成本，决定是否做第二套新主题，不预先承诺大量衣服。

## 六、共同基础设施

- ActionDirector：保护物理状态、事件去重、勿扰与低动态；动画不决定业务是否成功。
- 单一数据写入服务：本地存储、revision冲突、草稿、原子保存、失败恢复；Web/Qt不各存一份。
- 能力握手和按需query：同步升级宿主/stdio/Python/Web白名单，处理长中文请求，不每秒广播全文。
- 有预算的图片缓存：按解码尺寸计费、按需加载、退出清理；不把压缩素材体积当作内存占用。
- 回归：中文输入、多屏/DPI、锁屏恢复、存储失败、重复操作、无素材降级、旧默认动作全链路。

## 七、暂不做

自由单件混搭、动态配饰跟踪、骨骼引擎迁移、大量新主题、自动逐帧生图流水线、付费抽取、自动读取工作内容、自动关机或移动真实文件。
本轮仅整理设计文档；未实施运行功能、未制作角色素材、未执行GUI验收。
