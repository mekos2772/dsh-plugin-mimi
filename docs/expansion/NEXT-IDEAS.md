# 下一步能做什么：候选清单与取舍

> **实施状态（2026-10-29）**：已落地 A1 今日概览、C1 番茄钟衔接、B1 窗口边缘交互、
> 状态栏拖拽/极简、E1 低电量、E2 断网、E3 开机问候/退出告别。
> 其余条目仍未开工，保留供后续选择。

> 现状基线：87 个动作 / 10 套造型 / 45 套主动行为 / 时间感知 / 桌面走动 / 任务状态条。
> 下面按"投入产出比"分档，每条都给成本、风险和我自己的判断。

---

## 先说结论：我最推荐这 3 件

| 顺序 | 功能 | 一句话理由 |
|---|---|---|
| 1 | **今日概览 + 连续天数** | 把"陪着你"变成可见的数字，情感回报最高，且几乎不打扰 |
| 2 | **番茄钟自动衔接** | 已有专注服务和健康卡，只差编排，用户每天都会用到 |
| 3 | **状态栏可拖拽 / 贴边 / 极简** | 现在的位置写死在右上角，用户第一件事就是想挪它 |

---

## A. 陪伴感与情感回路

### A1. 今日概览 + 连续天数 ★★★
- **内容**：`今天陪你 2h15m · 专注 45m · 完成 2 个任务 · 记了 3 条便签`，以及"连续 7 天"。
- **落点**：状态栏小字、悬停气泡、右键菜单「今天」。
- **成本**：中（一个统计模块 + 三处展示）。
- **风险**：低。只存聚合数字，不存内容。
- **参考**：习惯类产品普遍用 streak + 角色化奖励提升黏性，见
  [Digital Habit Streak Calendar](http://commercialtoolry.com/fashion/digital-habit-streak-calendar-with-pet-avatar-rewards-vs-emoji-tracker-does-anthropomorphism-increase-emotional-investment)。

### A2. 好感度可视化与解锁 ★★☆
- **现状**：`affection.py` 已经有完整的好感度系统（0–100、每日上限、等级名称），但**界面上几乎看不到**。
- **可做**：菜单显示等级与进度；某些造型/动作按等级解锁；升级时播一次 `celebrate`。
- **成本**：小（读取已有数据）+ 中（解锁逻辑）。
- **风险**：低，但"锁内容"可能让用户不爽 —— 建议只锁装饰性内容。

### A3. 纪念日 / 生日 ★★
- **内容**：第一次使用纪念日、用户设置的生日，当天换节日造型 + 特殊问候。
- **成本**：小。
- **风险**：低。

---

## B. 桌面存在感（"它真的住在我桌面上"）

### B1. 窗口边缘交互 ★★★
- **内容**：Mimi 走到当前前台窗口的标题栏旁边坐下、从窗口边缘探出头、被窗口挡住时挪出来。
- **现状**：`desktop_sense.py` 已经能拿到前台窗口矩形（Windows 用 DWM，macOS 用 Quartz），只差"贴边"的移动逻辑。
- **成本**：中。
- **风险**：中 —— 窗口频繁变化时容易"追着跑"，需要节流和滞后。
- **参考**：桌面宠物社区里"贴边/吸附"是最常被提到的生命感来源，
  见 [Desktop Buddy](https://www.jxxy.net/ai/articles/a-gh-20261008-863-desktopbuddy-windows-ai-desktop-pet-live2d)（物理引擎 + 边缘吸附）。

### B2. 物理感：拖拽甩出 + 惯性 + 边缘反弹 ★★☆
- **现状**：已有 FALLING / LANDING 状态，但水平方向是自由落体式，没有惯性。
- **可做**：按释放速度给水平初速度，撞到屏幕边缘反弹，落地有轻微弹跳。
- **成本**：中。
- **风险**：中 —— 手感调不好会显得"滑"，需要反复试参数。

### B3. 多屏支持 ★☆
- **内容**：跨显示器走动、记住每块屏的位置、在不同屏幕间"搬家"。
- **成本**：大 —— 引擎目前默认单屏（`primaryScreen`），边界、碰撞、Dock 都要重算。
- **风险**：高，容易引入位置 bug。
- **判断**：除非你确实多屏办公，否则不建议现在做。

### B4. 桌面图标 / 文件交互 ★★
- **内容**：拖文件给它 → 已有 `file_drop_receive`；可扩展"拖到它身上 = 记一条便签 / 加入任务"。
- **成本**：小（已有 drop 通道）。
- **风险**：低。

---

## C. 工作流（真正能省事的部分）

### C1. 番茄钟自动衔接 ★★★
- **内容**：专注结束 → 自动弹休息卡（已有健康卡体系）→ 休息结束 → 问一句"再来一轮？"。
- **成本**：小-中。
- **风险**：低。
- **参考**：番茄工作法的核心就是"仪式化衔接"，现在缺的是结束后的那一步。

### C2. 状态栏多任务队列 ★★
- **内容**：有 2 个以上任务时显示 `+2`，点击展开列表。
- **成本**：小。
- **风险**：低。

### C3. 选中文本拖入 → 便签 ★★
- **内容**：把选中的文字拖到 Mimi 身上，直接变成一条便签。
- **成本**：小（复用 drop 与 notes）。
- **风险**：低。

### C4. 剪贴板感知 ★☆
- **内容**：复制了一大段文字后，气泡问"要记下来吗？"。
- **成本**：小-中（需要轮询剪贴板）。
- **风险**：**中高** —— 剪贴板里有密码、密钥。必须默认关闭 + 明确开关 + 本地判断长度/类型。
- **判断**：谨慎，默认不做。

### C5. DSH agent 状态映射 ★★★
- **现状**：已有 `harness_task_thinking`、`harness_tool_working` 两个动作，但映射很粗。
- **可做**：思考中 / 调用工具 / 等待审批 / 出错 / 完成，各自对应动作与状态条文案。
- **成本**：小。
- **风险**：低。
- **参考**：社区已经在把 agent 状态映射成桌宠表情，见
  [桌宠 30 年历史与 AI 复兴](https://www.kimi.com/resources/what-is-a-desktop-pet)。

## D. 玩法与养成

### D1. 小游戏扩展 ★★
- **现状**：滚球、接纸星。
- **可做**：猜拳（用 shake_head/nod）、点击连击、接住掉落的星星计分。
- **成本**：中。
- **风险**：低，但容易变成"一次性玩具"。

### D2. 收集要素 / 贴纸册 ★☆
- **内容**：完成任务、连续使用、特定时段互动获得贴纸。
- **成本**：中（需要一套 UI）。
- **风险**：中 —— 容易变成"为了收集而收集"。

---

## E. 系统级小反应

| 功能 | 内容 | 成本 | 风险 |
|---|---|---|---|
| E1 低电量 | 电量 <20% 时提醒休息/充电 | 小 | 低（平台 API 差异） |
| E2 网络断开 | 断网时 `look_down_sad`，恢复时 `cheer_jump` | 小 | 低 |
| E3 开机/关机 | 启动问候、退出告别 | 小 | 低 |
| E4 天气/节日 | 按天气换场景、节日换造型 | 中 | 中（要联网，且中国城市定位敏感） |
| E5 声音 | 偶尔的轻音效 | 中 | 中（很多人反感突然出声） |

---

## 我的取舍建议

**第一批（建议现在就做）**
1. 今日概览 + 连续天数
2. 番茄钟自动衔接
3. 状态栏可拖拽 / 贴边 / 极简

**第二批（下一轮）**
4. 窗口边缘交互
5. DSH agent 状态映射细化
6. 状态栏多任务队列
7. 选中文本拖入 → 便签

**暂时不做**
- 多屏（成本高、收益看人）
- 剪贴板感知（隐私风险）
- 声音（打扰）
- 天气（联网依赖）
