# Mimi 首批扩展设计（子代理独立稿）

> 状态：仅设计，尚未实现。本次只新增本文档；运行源码、素材、依赖和 Git 提交均未变更。
> 数量边界：严格 12 个新增动作 + 8 个新增功能；首期选择是下列条目的子集，不另增条目。

## 已核对基线与设计约束
- 已先检查会话技能目录：普通源码产品设计不匹配 Office 或 REA 技能，因此未调用这些技能。
- [正式清单](<../../pet/assets/characters/mimi/library_v1/manifest.json#L3088>)标明现有 23 套正式动作；退役项亦不作为本批新动作复活。
- 已有动作涵盖捂脸、落地恢复、任务思考、执行工具、倾听、坐下/坐姿/站起、入睡/侧睡/醒来、左右走、挥手、庆祝、摸头、挠肚、戳脸、击掌、接收拖入、吃面包/吃饱、点头。
- [动作库](<../../pet/mimi_app/src/mimi_pet/action_library.py#L38-L73>)只加载 `usable_actions` 中已启用且素材有效的条目；候选设计不等于运行期可用。
- [引擎](<../../pet/mimi_app/src/mimi_pet/engine.py#L312-L358>)已有闲置播放、强制替换与限定动作取消；新动作优先复用这些生命周期，不平添状态枚举。
- [陪伴服务](<../../pet/mimi_app/src/mimi_pet/companion.py#L245-L333>)已有专注/休息计时、暂停继续、勿扰；提醒增改、稍后、通知历史与锁屏暂停同样是基线。
- [面板](<../../lib/client.js#L260-L329>)已有计时、勿扰、指令、提醒及通知页；下列功能必须带来新增数据或交互，不给旧按钮换名充数。
- 新绘制统一沿用现有角色比例、透明底、512×768 画布与地面锚点；素材通过验收后才加入正式清单。
- 共用仲裁：拖拽/下落/落地/关闭优先；新动作不打断这些状态，也不抢用户当前互动。自动触发在勿扰/专注时停发，不积压补播。
- 所有非循环动作自然完成后回到 `idle`；用户取消或拖拽即时终止；失败不改变业务完成状态，缺素材降级为文字。

## 新增动作：12 个
| ID | 名字 | 触发 | 素材方案 | 打断 / 完成条件 |
|---|---|---|---|---|
| `exp_stretch_up` | 双臂伸展 | F01 卡片选择“伸展”并点开始；不替换已有休息计时 | 新绘制：双臂上举、伸展、收回，约 2.4 秒 | 共用仲裁；一遍完成或用户结束卡片即回闲置 |
| `exp_shoulder_roll` | 肩部放松 | F01 卡片选择“松肩” | 新绘制：双肩轻绕与放松，约 2 秒；不复用点头 | 共用仲裁；一遍完成；再次点击只重启卡片而不叠播 |
| `exp_eye_distance` | 眺望远处 | F01 卡片选择“远眺” | 新绘制：抬眼望向远处、收回视线，约 2 秒；不复用捂脸 | 共用仲裁；一遍完成，卡片剩余时长由 UI 显示 |
| `exp_water_sip` | 小口喝水 | F01 卡片点“已喝水” | 新绘制：持杯喝水与放杯，约 2.2 秒；不复用吃面包 | 共用仲裁；单次完成，连点同一卡片仅播放一次 |
| `exp_goal_pin` | 贴上目标签 | F02 新建并选中今日目标后 | 新绘制：拿便签贴于身侧再收手，约 1.8 秒 | 共用仲裁；仅保存成功触发，一遍完成；保存失败不播 |
| `exp_step_stamp` | 盖完成章 | F02 勾完一个目标的全部步骤后 | 新绘制：小印章按下并亮出印记，约 1.6 秒；区别于庆祝 | 共用仲裁；同一目标完成版本去重；撤销勾选不反播 |
| `exp_day_flip` | 翻日历页 | F03 成功启用一条重复规则后 | 新绘制：小日历翻一页，约 1.8 秒 | 共用仲裁；规则持久化后播一遍；编辑文本不重复触发 |
| `exp_pocket_note` | 收好便签 | F04 将临时便签成功存入本地后 | 新绘制：折纸放入口袋，约 1.8 秒；区别于接收拖入 | 共用仲裁；每次保存请求最多一遍，取消编辑不播 |
| `exp_card_present` | 展示小卡片 | F05 用户点击生成当日回顾后 | 新绘制：双手举起空白卡片，约 2 秒；正文只放面板 | 共用仲裁；一遍完成；不将截图或统计文字烘焙进素材 |
| `exp_ribbon_wear` | 戴上小缎带 | F06 用户预览或应用缎带配饰后 | 新绘制：佩戴手势；缎带独立叠层资产，约 2 秒 | 共用仲裁；应用成功播一遍；移除配饰即时清除叠层 |
| `exp_leaf_balance` | 托叶平衡 | F07 用户从动作收藏中手动播放 | 新绘制：掌心托叶并轻晃，约 2.6 秒；非随机气氛动作 | 共用仲裁；单次完成；收藏与否不改变动作本体 |
| `exp_bookmark_place` | 放入书签 | F08 保存桌面停靠位后 | 新绘制：在脚边放小书签再收回，约 1.8 秒；不复用落地恢复 | 共用仲裁；位置保存成功播一遍；恢复位置只移动不补播 |

## 新增功能：8 个
| ID | 名字 | 交互 | 依赖 | 验收 |
|---|---|---|---|---|
| F01 | 引导式微休息卡 | 面板手动挑选伸展/松肩/远眺/喝水，展示单步指引与完成按钮；不创建另一套计时器 | 新增卡片运行态、动作路由及前四套对应动作；复用现有勿扰判定 | 四类卡均可开始/结束；拖拽中不抢播；勿扰下仍可手动操作；刷新不重复确认完成 |
| F02 | 今日目标拆步 | 新建一个目标，添加最多 5 个步骤，勾选与撤销；可与现有专注关联但不强制启动计时 | 目标/步骤本地模型与版本号；`exp_goal_pin`、`exp_step_stamp`；原专注模型保持兼容 | 保存后重启仍在；全勾只触发一次盖章；撤销后可再完成；取消专注不删除目标 |
| F03 | 重复规则提醒 | 在现有提醒上新增“每日/每周指定日”规则；显示下一次，并可只完成本次或停用规则 | 重复规则模型、明确本地时区与 occurrence 去重；复用 Reminder 与 Notice；`exp_day_flip` | 完成本次生成唯一下一次；重启不重复；休眠错过多次只呈现一次待处理；规则停用后不再生成 |
| F04 | 本地便签口袋 | 新便签页录入短文本，支持编辑、删除、复制及搜索；不自动读取剪贴板 | 独立便签集合与 200 字上限；面板状态同步；`exp_pocket_note` | 搜索只命中文本；删除即时同步；重启保留；保存重复请求不出现重复便签 |
| F05 | 当日陪伴回顾 | 手动生成今日目标完成数、实际专注分钟与微休息次数；只展示本地统计，不弹出推送 | 按本地日期聚合的完成事件与实际计时片段；`exp_card_present` | 取消/暂停时间不算专注；重启前后统计一致；无数据有空态；清空回顾不删除目标及提醒 |
| F06 | 配饰预览柜 | 面板试戴、应用或移除首款缎带；预览与已保存选择分离 | 本地配饰配置、Qt 渲染叠层与锚点；`exp_ribbon_wear`；素材授权清单 | 取消试戴恢复原样；拖拽时叠层跟随；不遮挡脸；重启保持已应用选择，缺素材回退无配饰 |
| F07 | 动作收藏面板 | 列出正式可用动作，收藏最多 6 个并拖动排序；按“播放”显式触发，不替换当前互动 | ActionLibrary 元数据快照、收藏 ID 集合；`exp_leaf_balance`；协议播放白名单 | 同名 ID 不重复；失效 ID 显示不可用且可移除；拖拽/睡眠时返回忙碌；排序重启保留 |
| F08 | 桌面停靠书签 | 保存最多 3 个命名位置，点击恢复；显示器变化时先预览校正位置再确认 | 显示器标识、逻辑坐标/缩放与可用区映射；复用现有位置/边界约束；`exp_bookmark_place` | 同屏恢复误差≤2逻辑像素；屏幕移除仍可见；拖拽中禁恢复；不改变现有自由摆放开关 |

## 首期取舍：仅 3 动作 + 2 功能
- 动作：`exp_stretch_up`、`exp_goal_pin`、`exp_step_stamp`；功能：F01、F02。
- F01 首期仅开放“伸展”卡，其余三类显示为未开放，不用旧动作冒充；F02 首期保留一目标、五步骤上限。
- 选择理由：伸展提供直观新表演，目标签和完成章形成“设定→执行→收获”闭环；先避开日历、跨屏与叠层复杂度。
